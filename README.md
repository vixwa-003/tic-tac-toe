# Tic Tac Toe Download Website

## Run in VS Code
1. Extract the ZIP.
2. Open the `tic-tac-toe-download` folder in VS Code.
3. Open `index.html` with a browser (or use the Live Server extension).
4. The **Download APK** buttons download `apk/tic-tac-toe.apk`.

## Publish
Upload the entire folder to a static hosting service. Keep the `apk` folder and its filename unchanged, or update the `href` in `index.html`.

The APK included is the file supplied for this project.
